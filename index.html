Sobre el proyecto

Este proyecto consiste en una aplicación cliente-servidor desarrollada en Python. Permite registrar usuarios, iniciar sesión y acceder a una página de bienvenida protegida.

Tecnologías utilizadas

  • Python
  • Flask
  • SQLite
  • Requests
  • Werkzeug

Funcionalidades

  • Registro de usuarios con POST /registro.
  • Inicio de sesión mediante POST /login.
  • Contraseñas almacenadas mediante hash.
  • Persistencia de usuarios con SQLite.
  • Acceso protegido a GET /tareas.
  • Cliente de consola con menú interactivo.
